# giftshope-commerce
E-Commerce Platform (MERN Stack)
A full-stack e-commerce application built using the MERN stack (MongoDB, Express.js, React, Node.js). Designed for selling unique and gift products, the platform includes:
-  Home Page – clean landing page showcasing products
-  Cart Page – add, update, and remove items
-  Product Listing & Detail Pages – browse and view product information
-  uthentication – login and logout functionality
-  MERN Stack Integration – seamless backend and frontend workflow
